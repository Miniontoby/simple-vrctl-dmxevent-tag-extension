# Simple VRC.TL DMX Event tag Extension

A simple browser extension to add a DMX Event tag to https://vrc.tl when the event description includes `#dmx-event`


## Installation

### Chrome

1. Download zip and unzip into a folder, OR clone the repository to a folder.
2. Go to chrome://extensions in browser
3. Enable developer mode
4. Click "Load unzipped extension"
5. Select the folder
6. Now to go vrc.tl (and reload if it was already open)

### Firefox

1. Download zip and do NOT unzip the zip, as firefox requires zips
2. Go to `about:debugging#/runtime/this-firefox`
3. Click "Load Temporary Extension"
4. Select zip
5. Now to go vrc.tl (and reload if it was already open)

Every restart of firefox you need to re-add it, thats just a firefox thingy.


## Technical notes

Technically you can use the same chrome zip/manifest on firefox, but just for officiality, I did make a custom manifest for firefox.
